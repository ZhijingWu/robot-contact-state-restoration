# Proposed homepage entry — not applied

**Robot-Contact State-Restoration Study** · Independent Simulation · 2026

Studied whether incomplete simulator-state restoration changes contact dynamics and command selection using official Agentic Real2Sim components in an independently constructed Franka/Robotiq scene. Across 16 paired seeds, position-only restoration produced measurable physical deviations but 0/16 command-choice flips; complete-state controls matched exactly. Independent-process reproducibility was verified. An incremental empirical finding, with no native converted-episode or real-robot claim.
